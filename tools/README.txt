saxon-he.jar  -  Saxon-HE 10.9 (Saxonica, Mozilla Public License 2.0)
Source: https://repo1.maven.org/maven2/net/sf/saxon/Saxon-HE/10.9/

Used by schematron.py to run the official Factur-X EN 16931 business-rule
validation (FACTUR-X_EN16931.xslt, shipped inside the "factur-x" Python package).
Requires a Java runtime (8 or newer) on the PATH. Without Java or without this
file the app still works; the validation status is then reported as "nicht geprüft".
